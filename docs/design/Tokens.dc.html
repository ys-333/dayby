Every number wears the sans, including the big ones — a serif figure reads as decoration. The serif carries language only: the day’s headline, insight sentences, screen titles.

Newsreader ships as a bundled pubspec fonts: entry — one weight, an asset rather than a package. Never google_fonts: runtime fetching is the wrong shape for an app that is offline-first by design. The UI sans is whatever the device ships, with FontFeature.tabularFigures() wherever numbers align in a column.

Rules that hold the system together
01Status is never colour alone. Every state carries a distinct shape, a glyph and a spoken label.
02No red anywhere. The strongest negative in the palette is clay, and it is reserved for a closed, missed day.
03Daily and period commitments never share a group. A weekly target cannot be late today, so it never sits in the same list as something that can.
04The day’s headline counts down to zero. A percentage of today is a verdict; a count of what is left is a task.
05The future is outline only. Nothing unlived is ever drawn as a failure.
06Skips are shown, never hidden, and never struck through — a skip is a decision, not a deletion.
